# Myanmar: Empire of Warriors

A historical turn-based strategy game inspired by Myanmar's kingdoms and military history.

## Current development target

**Phase 1 — Playable Android prototype**

- Engine: Godot 4.x (GDScript)
- Platform: Android first; desktop editor testing during development
- Camera / board: 2D isometric-style hex battlefield
- First scenario: fictionalized Konbaung (Red) vs Hanthawaddy (Gold) encounter
- Core loop: select a unit → move or attack → end turn → enemy AI responds

## Historical approach

The first battle is a gameplay prototype, not a claim to depict one exact historical battle. Historical names, uniforms, flags, weapons, and campaign events will be researched and reviewed before inclusion.

## Build

Open this folder in Godot 4.x. The first prototype will use built-in drawing and placeholder shapes so it can run before final art assets are ready.
